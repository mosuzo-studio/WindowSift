# WindowSift website

Official English and Simplified Chinese product website for Mosuzo Studio.

- Production: https://windowsift.mosuzo.com
- English routes at /; Chinese routes at /zh-cn.
- Based on SnipArc-site: retained v3 header/footer, Astro static output, locale-aware navigation and GitHub Pages workflow.

## Development

Node.js >=22.12.0. Run npm ci, then npm run dev.
Before publishing: npm run check, npm run build, npm run verify.

See docs/terminology.md for product evidence, screenshot boundaries and public release status. See docs/DEPLOYMENT.md for Pages and custom-domain setup.

No public standalone software download is linked until a release is verified.
