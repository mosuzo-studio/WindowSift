# WindowSift

WindowSift 的英文与简体中文官网。它追踪窗口来源，展示窗口树、窗口属性和短暂出现的弹窗。

- 简体中文: https://windowsift.mosuzo.com/zh-cn/
- 工作室: https://mosuzo.com/ · 全部产品: https://mosuzo.com/products/
- GitHub: https://github.com/mosuzo-studio/WindowSift

[English](README.md) · **简体中文**

## 开发

Node.js >=22.12.0。执行 `npm ci`，然后 `npm run dev`。发布前运行 `npm run check`、`npm run build`、`npm run verify`。

站点沿用 SnipArc-site 的 v3 页头/页脚、Astro 静态输出、语言导航与 GitHub Pages 工作流。产品证据、截图边界与公开发布状态见 `docs/terminology.md`；Pages 与自定义域名配置见 `docs/DEPLOYMENT.md`。
